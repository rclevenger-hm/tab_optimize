# Tab Optimize Privacy

Tab Optimize does not collect, sell, transmit, or share personal information or browsing history.

The extension uses Chrome's local extension APIs only. It stores settings in `chrome.storage.sync` and operational state (tab activity timestamps, aggregate suspension counts, and the IDs of the most recent suspended batch) in `chrome.storage.local`.

Tab Optimize does not use analytics, advertising, remote code, content scripts, or external network services. It requests no website host permissions.
